# Presentación del proyecto

## Nombre del proyecto

**Agente PETE**

## ¿Qué es el proyecto?

Agente PETE es una aplicación sencilla que permite que un usuario tenga un perfil guardado y pueda registrar conversaciones. La idea principal es que el sistema recuerde datos básicos del usuario, como su nombre y el modelo de IA que prefiere usar.

## Objetivo general

Diseñar y programar un sistema de clases que permita guardar información del usuario y mantener un historial de conversaciones, aplicando conceptos de programación orientada a objetos.

## Objetivos específicos

- Identificar los objetos principales del sistema.
- Crear clases con atributos y métodos claros.
- Aplicar herencia mediante una clase abstracta.
- Aplicar polimorfismo usando una interfaz de almacenamiento.
- Usar sobrecarga y sobreescritura de métodos.
- Validar las entradas que escribe el usuario.
- Guardar la información de forma local usando archivos JSON.

## Funcionamiento general

El usuario entra a la aplicación y puede:

1. Configurar su perfil.
2. Escribir su nombre.
3. Elegir el modelo de IA que desea usar.
4. Guardar una conversación.
5. Consultar el historial guardado.
6. Salir del programa.

## Importancia del proyecto

Este proyecto es importante porque permite practicar cómo dividir un problema en objetos. También ayuda a entender cómo las clases pueden trabajar juntas para resolver una situación real. En este caso, el sistema necesita guardar datos, cargar datos y organizar información del usuario.
